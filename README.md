# Outdoor Boys

Adventure guiding company in the making. Bringing foreign visitors into Taiwan's rivers and canyons through English-first day trips — river tracing (溯溪), canyoning, and the kind of outdoor experiences Taiwan's geography makes possible but almost nobody runs for English-speaking travelers.

**Status:** pre-launch. Targeting first paid foreign-tourist trip by **April 2027**.

**Founders:** Dino · Duncan · Luke · Apple
